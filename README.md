Library Management System

A full-featured Library Management System built using Java Spring Boot and MySQL, with HTML/CSS frontend.
It allows members to borrow and purchase books, view transaction history, and manage profiles. Admins can manage users, books,
and system activity through a dedicated dashboard.

# Features

- Member Functionality
- Login / Signup
- View & Edit Profile
- Browse Books
- Borrow or Buy Books
- View Transaction History

# Admin Functionality

- Admin Login
- Manage Book Inventory (Add/Edit/Delete)
- View and Manage Member Info
- Monitor Borrowing & Purchase Activity

# Tech Stack

- **Backend**: Java Spring Boot
- **Frontend**: HTML, CSS
- **Database**: MySQL
- **IDE**: Visual Studio Code

# System Architecture

- Follows **SOLID principles**
- Uses factory design pattern 
- Layered architecture (Controller → Service → Repository)
